# Code of Conduct

This project adopts the **Contributor Covenant**, version 2.1, as its code
of conduct.

The full text is published at:

> https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project — whether by filing an issue, commenting
on one, or contributing code — you agree to abide by its terms.

## Reporting

Concerns about conduct in this repository can be reported privately via:

- **https://agileviz.com/contact/** — reaches the project maintainer
  directly.

Reports are reviewed promptly and handled confidentially. The maintainer
is committed to providing a welcoming, professional, and respectful
environment for everyone who participates.

## Scope

This code of conduct applies within all project spaces — issues, pull
requests, discussions, and any community channels associated with this
repository — and also when an individual is representing the project in
public spaces.

## Enforcement

The maintainer is responsible for clarifying and enforcing standards. The
maintainer may take any action they deem appropriate, up to and including
removing comments, closing issues, or blocking contributors, in response
to conduct judged inconsistent with this code.
