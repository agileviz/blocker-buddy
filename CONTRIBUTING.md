# Contributing

Thanks for your interest in contributing! This is the public source code
for an AgileViz Marketplace plugin, maintained by
[AgileViz, LLC](https://agileviz.com).

## How contributions are handled

This project is maintained with limited capacity. Contributions are
evaluated on a case-by-case basis under the following guiding principles:

- **Bug reports**: welcomed. Please include reproduction steps, your ADO
  process template (Scrum / Agile / Custom), and screenshots where
  applicable. Open a GitHub issue.
- **Feature requests**: welcomed but not prioritized externally. Open a
  GitHub issue describing the use case; we evaluate against the product
  roadmap.
- **Pull requests**: small bug fixes are most welcomed. Larger PRs (new
  features, architectural changes) are best preceded by a GitHub issue
  to confirm fit before significant work.
- **Translations / internationalization**: not currently in scope; reach
  out via https://agileviz.com/contact/ to discuss.

## Local development

See [README.md](./README.md) for build commands and local development
setup.

## Code style

ESLint configuration is included. Please run `npm run lint` before
submitting a PR.

## Tests

Jest is used for testing. Please add or update tests for bug fixes and
new functionality. Run `npm test` to verify.

## Security issues

**Do not report security vulnerabilities via public GitHub issues.** See
[SECURITY.md](./SECURITY.md) for the responsible disclosure process.
