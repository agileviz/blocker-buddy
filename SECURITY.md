# Security Policy

## Reporting a vulnerability

To report a security vulnerability in this repository, please use one of
the following channels:

- **GitHub Security Advisory** (preferred): open a private advisory via
  the *Security* tab of this repository.
- **Contact form**: https://agileviz.com/contact/

Legitimate reports are acknowledged within 2 business days.

## Scope

This repository is part of the AgileViz open-source project. Public
repositories are subject to continuous automated scanning (CodeQL,
SonarCloud, Dependabot) and community review.

**This repository is out of scope for AgileViz's monetary bug bounty
program**, which focuses on hosted AgileViz services at agileviz.com.
Responsible disclosures for open-source code are welcomed and disclosers
receive public credit in release notes (with permission).

For the full AgileViz security policy — including bounty scope,
out-of-scope items, and coordinated-disclosure expectations — see:
**https://agileviz.com/security/**

## Supported versions

The latest published version receives security updates. Customers using
older versions should update; backports are not provided.
